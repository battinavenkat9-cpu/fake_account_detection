Modules demonstrated

  3. Machine-learning classification
  4. Result and risk-score display
  5. History and summary statistics
Scope and limitations: The presentation describes a broader system with social-media data collection, real-time processing and platform actions. This local implementation does not connect to Instagram, Facebook or X, scrape profiles, block accounts, or use a real labeled dataset. It uses manually entered values and generated training examples. Replace the demo data with a properly licensed, representative labeled dataset and evaluate false positives/negatives before any real-world use.
